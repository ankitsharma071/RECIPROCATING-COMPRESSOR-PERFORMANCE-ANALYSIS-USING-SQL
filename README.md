# Reciprocating Compressor Performance Analysis

## 📌 Project Overview

This project analyzes the performance characteristics of reciprocating
piston compressors using SQL and Power BI.

The analysis focuses on compressor efficiency, pressure ratio,
suction superheat, refrigerant selection, and application-specific
operating conditions.

## 🎯 Objectives

- Analyze the effect of pressure ratio on volumetric and isentropic efficiency
- Investigate the effect of suction superheat on compressor performance
- Benchmark refrigerants based on compressor efficiency
- Compare efficiency degradation across refrigerants and pressure ratios
- Identify refrigerant performance across different application temperature zones

## 🛠️ Tools & Technologies

- MySQL
- SQL
- Excel / CSV
- Data Cleaning & Exploratory Analysis

## 📊 Dataset

Source:
(https://zenodo.org/records/17599603)

Dataset contains approximately 32,000 compressor performance data points
covering different refrigerants, operating conditions and compressor
configurations.

## 🔍 Key Findings

### 1. Pressure Ratio Dynamics

Volumetric efficiency decreases substantially as pressure ratio increases,
while isentropic efficiency reaches an optimal region around PR = 3–6.

### 2. Suction Superheat Effects

Increasing suction superheat shows an improvement in observed isentropic
efficiency up to approximately 45 K, while higher superheat is associated
with lower volumetric efficiency.

### 3. Refrigerant Benchmarking

Different refrigerants exhibit distinct compressor performance
characteristics. Propene, Propane, CO₂, R1234ze(E), and R134a were
benchmarked using volumetric and isentropic efficiency.

### 4. Operating Envelope Sensitivity

Low evaporation-temperature operating conditions are associated with
higher pressure ratios and lower volumetric efficiency, while higher
evaporation temperatures generally correspond to lower pressure ratios
and improved volumetric efficiency.
